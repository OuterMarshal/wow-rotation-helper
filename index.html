Frequently asked questions

Quick answers before you download.

Which game versions are supported?
The helper ships with rotation profiles for current retail (including the latest class tuning) as well as Classic Era and Wrath Classic, so you can switch profiles without reinstalling.
Does it work for every class and spec?
Yes. Each class and spec has its own priority-based rotation profile, covering single-target, cleave, and AoE priority lists with proc-aware rules.
How does proc detection work?
The helper continuously scans your active auras and buffs, matching them against the proc rules defined in your class profile. When a proc is detected, the spell queue updates instantly and highlights the empowered ability.
Is it free and open source?
Completely. WoW Rotation Helper is free to download and open source — you can review the code, report issues, or contribute new rotation profiles on the project page.
